Skin Cancer Detection

Python FastAPI Gemini Vision Computer Vision HTML/CSS/JS
View on GitHub

The Problem

Skin lesion images can be difficult for non-specialists to interpret, especially when users are unsure whether a spot may require medical attention. This project explores how AI vision models can support early screening by providing structured risk estimates, image-quality feedback, and clear follow-up guidance.

Approach

I built an AI-powered skin lesion screening application with a FastAPI backend and a custom web interface:

  • Image analysis — used Gemini Vision to analyze dermoscopy or clinical skin lesion images
  • Risk estimation — estimated malignancy risk across melanoma, basal cell carcinoma, and actinic keratosis / squamous cell carcinoma
  • Multi-run inference — aggregated repeated model outputs to improve result stability
  • Quality control — added lighting and framing checks to reject unreliable images
  • Web interface — built a custom HTML/CSS/JavaScript frontend served through FastAPI static files
  • User support — added AI-generated summaries, chatbot guidance, and nearby medical facility lookup using OpenStreetMap / Overpass API

Results

  • Built a working end-to-end system connecting image upload, FastAPI endpoints, Gemini Vision analysis, and frontend visualization
  • Generated risk levels based on malignant class probabilities for three skin cancer-related categories
  • Added image-quality gating to reduce unreliable predictions from poor lighting or framing
  • Created an interactive user experience with probability display, result summaries, chatbot support, and nearby facility search

Reflections

This project helped me better understand how to design AI applications for sensitive healthcare-adjacent use cases. The main challenge was not only generating model outputs, but also making the system safer and more useful through quality checks, clear risk communication, and reminders that the tool is for research and educational purposes rather than medical diagnosis.
