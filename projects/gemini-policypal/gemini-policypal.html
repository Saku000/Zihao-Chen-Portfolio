Gemini PolicyPal

Python Streamlit Gemini / OpenAI Sentence Transformers RAG
View on GitHub

The Problem

Insurance policies are long, complex, and hard to interpret. Users struggle to quickly understand coverage details, identify exclusions, or compare multiple policies. Traditional keyword search doesn't work well with unstructured legal text, and manual comparison is slow and error-prone.

Approach

I built an end-to-end AI system using a Retrieval-Augmented Generation pipeline:

  • Document processing — parsed uploaded PDFs, split them into structured chunks, cleaned and standardized text
  • Semantic retrieval — generated embeddings for each chunk and implemented similarity-based retrieval for context-aware search
  • RAG question answering — retrieved top relevant chunks, constructed grounded prompts, and generated answers strictly based on source content
  • Policy comparison — designed a multi-document module for side-by-side analysis of coverage, exclusions, and conditions
  • Interface — built an interactive Streamlit app supporting multi-file upload and real-time Q&A

Results

  • Working end-to-end system integrating document parsing, retrieval, and LLM generation
  • Improved information retrieval accuracy compared to keyword-based approaches
  • Structured comparison of complex policy documents
  • Interactive interface for real-time document analysis

Reflections

RAG pipelines proved highly effective for grounding LLM responses in real data. The main challenges were handling varied document formatting and designing reliable chunking strategies for long documents. Future directions include citation highlighting, improved comparison visualization, and domain-specific embeddings for higher accuracy.
