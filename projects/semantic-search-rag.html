Semantic Search & RAG for Medical Literature

Python Sentence Transformers OpenAI API Streamlit PyMuPDF NumPy
View on GitHub

The Problem

Medical research papers are information-dense and terminology-heavy. Traditional keyword search falls short when users need not just document retrieval, but grounded answers to natural-language questions based on relevant evidence across a large corpus.

Approach

I designed and built an end-to-end NLP pipeline with a modular architecture:

  • PDF extraction — text extraction and cleaning from 100+ medical research papers
  • Paragraph-based chunking — preserving semantic coherence with length-bounded chunks
  • Dense embeddings — SentenceTransformer embeddings with cosine-similarity retrieval
  • RAG generation — optional answer generation via OpenAI with strict prompting constraints to reduce hallucination
  • Retrieval tuning — doc-level deduplication and keyword prefilter with fallback for improved precision
  • Interfaces — both CLI and Streamlit web app

Results

  • Semantic search over 100+ medical papers with top-K dense retrieval
  • Natural-language question answering grounded in source evidence
  • Doc-level deduplication improved evidence diversity across results
  • Keyword prefilter improved precision for heterogeneous biomedical topics

Reflections

This project deepened my understanding of the trade-offs between retrieval quality, chunk granularity, and answer grounding. The paragraph-level chunking approach balanced coherence and retrieval precision well. Future work could include biomedical-specific embedding models like PubMedBERT, cross-encoder reranking, and page-level citation linking.
